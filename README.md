# Java Design Patterns & LLD Practice

A collection of Java implementations and practice problems for
learning Design Patterns, SOLID principles, and Low-Level Design (LLD).

## 📚 Contents

### Design Patterns

- Builder Pattern
- Decorator Pattern
- Factory Pattern
- Observer Pattern
- Singleton Pattern
- Strategy Pattern

### SOLID Principles

- Single Responsibility Principle
- Open/Closed Principle
- Liskov Substitution Principle
- Interface Segregation Principle
- Dependency Inversion / Dependency Injection

### LLD Practice

- BookMyShow
- Elevator System
- Parking Lot
- Splitwise
- RateLimiter

## 🛠️ Tech Stack

- Java
- Object-Oriented Programming
- Design Patterns
- SOLID Principles
- Low-Level Design

## 🎯 Purpose

This repository is primarily for practicing and implementing
common object-oriented design concepts and LLD problems in Java.

Each example focuses on understanding the design and the
trade-offs involved rather than building production-ready systems.
